# Угадай мой рисунок

Игра, в которой свёрточная сеть угадывает рисунок по мере того, как ты рисуешь. Открой `index.html` в браузере. Веса модели встроены в страницу, игра работает офлайн.

Модель знает восемь классов: кошку, рыбу, самолёт, яблоко, велосипед, гриб, парусник и зонт. Сеть угадала 3 739 из 4 000 тестовых рисунков (93,5%). Линейная модель на том же тесте набрала 84,1%.

## Файлы проекта

- `index.html` — игра и реализация предсказания в браузере.
- `train.py` — обучение CNN и линейной модели на одинаковом разбиении.
- `model.pt` — веса обученной CNN для PyTorch.
- `prepare_data.py` — проверка размеров файлов на первых трёх классах.
- `show_sketch.py` — вывод первого рисунка кошки в терминал.
- `data/` — 40 000 рисунков, которые использовались при обучении и проверке.

## Повторить обучение

Команды для macOS. Используй Python 3.12.

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python prepare_data.py
python show_sketch.py
python train.py --output runs/model.json
```

Скрипт перемешивает рисунки каждого класса с фиксированным seed и делит их на 32 000 для обучения, 4 000 для выбора эпохи и 4 000 для итогового теста. Новые веса сохраняются в `runs/model.pt`, а метрики и веса для браузера — в `runs/model.json`.

## Данные

Рисунки предоставлены Google в [Quick, Draw! Dataset](https://github.com/googlecreativelab/quickdraw-dataset) под лицензией [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). В репозитории сохранены первые 5 000 строк из каждого из восьми файлов `.npy`. Каждый рисунок содержит 784 значения яркости.
